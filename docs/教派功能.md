# 教派功能

教派是出行前的选择与准备框架。当前内置「黄金教」示例，配置位于 `sects/golden.yml`。

- `/sf sect list`：查看教派。
- `/sf sect join golden`：选择黄金教。
- `/sf sect prepare`：为本次出行领取黄金信号枪和黄金酒；同一次出行只能准备一次。
- `/sf sect status`：查看教派、准备状态和黄金酒剩余时间。
- `/sf sect finish`：结束本次出行，供手动测试或外部副本流程使用。

入教收益是每次出行前领取一把黄金信号枪和一瓶黄金酒。黄金信号枪右键会在玩家前方召来黄金教商人；黄金酒右键饮用后，在持续时间内通过 `SourceForgeCombatAPI` 为玩家提供 `1.1` 输出倍率，覆盖 SourceForge 统一处理的近战、远程和普通实体伤害。

## 扩展方式

每个教派独立一个文件：插件数据目录的 `sects/<id>.yml`。文件同时定义教派属性、奖励和 SourceTasks 对话；新增教派只需要复制 `golden.yml`、修改 `id/display-name/npc/dialogue`，不需要修改 Kotlin。奖励行为通过 `behavior` 注册扩展，外部出行插件应调用 `SourceForgeSectAPI.prepareJourney(player)` 和 `finishJourney(player)`，不需要直接操作 PDC。

对话由 SourceTasks 动态注册，NPC 的稳定 id 由教派文件的 `npc.id` 指定。以黄金教为例，管理员站在目标位置执行 `/snpc create villager golden_priest`，玩家右键后会进入 SourceTasks 的 HUD/打字机/选项对话；对话选项通过 SourceForge 命令动作完成入教和领取物资。
